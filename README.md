# 2DMMO

A top-down 2D pixel art online game about crafting, built in Godot 4 with GDScript.

Each server is a town of crafters preparing for waves of invasion. Players gather, craft, trade, and vote together through their crafting guilds on how to spend the town's resources.

## Getting started

1. Install [Godot 4](https://godotengine.org/download) (standard version, not .NET).
2. Clone this repo with [GitHub Desktop](https://desktop.github.com/).
3. In Godot, create or import the project inside this folder.
